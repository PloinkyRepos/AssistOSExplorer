WebMeet LiveKit AI Agent Documentation

This optional Ploinky agent owns the self-hosted LiveKit Agents worker for WebMeet AI participants. It is launched explicitly by stacks that want self-hosted AI participants and is not part of Explorer's default dependency graph.

The worker also owns scribe runtime integration with the internal WebMeet STT service and WebMeet transcript API. It mounts the sibling WebMeet agent only to reuse the canonical event contract while keeping the native LiveKit dependency tree local to this agent. The DS specifications are the source of truth for runtime ownership, dependencies, credential derivation, and the operator steps required to enable AI dispatch.
