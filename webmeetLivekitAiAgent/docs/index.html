WebMeet LiveKit AI Agent Documentation

This optional Ploinky agent owns the self-hosted LiveKit Agents worker for WebMeet AI participants. It may launch through a no-wait dependency edge so fresh WebMeet startup can continue while the native LiveKit worker dependency tree prepares in the background.

The DS specifications are the source of truth for runtime ownership, dependencies, LiveKit credential derivation, and the operator steps required to enable AI dispatch.
