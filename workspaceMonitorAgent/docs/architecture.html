Documentation / Architecture

Architecture

The supervisor starts the metrics collector, daily log-maintenance worker, and Ploinky AgentServer. It restarts the collector or maintenance worker with bounded backoff if either child exits unexpectedly.

Collector and storage

The collector signs /api/edge/workspace-metrics?follow=1, consumes newline-delimited snapshots, and derives aggregate workspace, Router, and per-runtime CPU and memory series. For each received sample it atomically replaces current-snapshot.json with an allowlisted projection and persists historical series at most once per ten seconds. The two writes have independent bounded retry state.

The private metrics stream is the only source for live samples. The administrator-only snapshot tool reads the current projection and marks it stale after fifteen seconds. SQLite stores historical samples in resource_samples with WAL mode and removes records older than the thirteen-month retention window.

Log maintenance

At startup and at each UTC day boundary, the maintenance worker sends the configured retention period to Ploinky's private log service. It uses bounded retry backoff when the service is unavailable. Router and Policy log contents remain owned by Ploinky.
