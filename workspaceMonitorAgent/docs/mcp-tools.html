MCP tools

Every tool runs through tools/workspace_monitor_tool.sh. The wrapper obtains the verified invocation actor and rejects the request unless the actor is an administrator.

ToolInputsPurposeObservable result
workspace_monitor_snapshot_getNone.Read the latest allowlisted resource projection collected from Ploinky.The sanitized current snapshot plus availability, age, and stale-state metadata.
workspace_monitor_settings_getNone.Inspect the active monitoring thresholds and log-retention configuration.Current normalized thresholds and log retention.
workspace_monitor_settings_updateWorkspace and Router CPU/memory thresholds plus logRetentionDays.Change administrator-controlled alert thresholds and retained-log duration.Persisted normalized settings; invalid ranges fail.
workspace_monitor_history_queryISO from and to; optional maxPoints and series list.Retrieve bounded historical workspace, Router, or per-runtime metric series.Bucketed aggregate or runtime series with values and thresholds.
workspace_monitor_logs_listsource: router or policy.Discover the active and retained logs available for an authorized source.Available active and archived Ploinky logs.
workspace_monitor_logs_getSource, log name, optional maxBytes.Read a bounded portion of one selected live or archived log.Bounded content for the selected live or archived log.
workspace_monitor_logs_searchSource, required query, optional limit.Locate matching text across the active log and retained archives.Matches across the active log and retained archives.

The MCP configuration is the authoritative list of seven tools. It does not declare a public HTTP API owned by Workspace Monitor.
