Workspace Monitor Agent

Administrator-only live workspace monitoring with durable SQLite history for all available Agents aggregate, Router, and individual runtime CPU and memory samples.

Thresholds classify and display spikes only for the aggregate Agents and Router series; individual runtime history is independent of those thresholds. History queries support up to 50,000 points per series.

The Resources tab selects the first runtime by default and provides a recent CPU chart, current CPU and memory values, and persisted CPU and memory history for each selectable runtime.
