Workspace Monitor Agent

Workspace Monitor gives an administrator a live view of workspace and runtime CPU and memory usage, a bounded SQLite history, and access to retained Ploinky Router and Policy logs. The agent runs beside Ploinky and is surfaced in Explorer through the workspace-monitor plugin.

Administrative Boundary

All six Model Context Protocol tools are administrator-only. The agent does not monitor arbitrary host processes, expose a public metrics endpoint, or allow ordinary participants to change thresholds or read Ploinky logs.
