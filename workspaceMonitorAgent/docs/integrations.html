Documentation / Integrations

Integrations

Explorer

The workspace-monitor IDE plugin is declared by the agent and mounted by Explorer when the runtime plugin policy enables it. The plugin is an administrator-only entry point and does not read SQLite or Ploinky files directly.

Ploinky metrics

The collector uses a private Router assertion to request the streaming workspace metrics route. It records the Router metrics separately and derives the workspace agent aggregate from available runtime metrics, or from the total minus Router when runtime details are absent.

Ploinky logs

Log listing, reading, searching, and retention maintenance call Ploinky's private log service. Workspace Monitor sends signed requests and returns the service response; Ploinky remains responsible for log ownership, active files, and retained archives.

Boundary

The repository does not establish a public browser route or direct runtime-port contract for this agent. Consumers must use the configured MCP tools through Ploinky.
