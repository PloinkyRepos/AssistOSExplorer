gitAgent Documentation

This directory now lives inside the fileExplorer repository and hosts the gitAgent MCP agent.

The agent is integrated in Ploinky and consumed by Explorer workflows from the internal AssistOSExplorer repository.

At runtime, Git functionality is exposed through MCP tools and executed by gitAgent/tools/git_tool.sh.

Operational Role

gitAgent mediates Explorer actions and Git process execution through MCP contracts declared in gitAgent/mcp-config.json. The agent validates repository scope against workspace roots before running commands, so Git operations stay inside approved paths.

Remote workflows reuse the same boundary, including optional GitHub authentication flows, which keeps token handling and command execution logic out of the UI layer.

Repository Scope

The repository can host multiple Ploinky agents over time. The current documentation set focuses on gitAgent and its role as a Git intermediary for Explorer-facing flows.

Validation rule: run the Git agent test suite for code changes, together with docs and specification updates.
