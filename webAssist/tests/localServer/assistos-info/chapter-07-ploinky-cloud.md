# Chapter 7: Ploinky Cloud

Ploinky Cloud is the hosted and managed version of the Ploinky platform. It is designed for users and organizations that want the capabilities of Ploinky without managing the infrastructure themselves.

## Vision

Ploinky is open source under the MIT License. Ploinky Cloud adds a managed operational layer for organizations that want hosted workspaces, managed agent environments, scaling, monitoring, security updates, and commercial support.

The purpose of Ploinky Cloud is not to replace the open-source platform. Its role is to make Ploinky easier to adopt in organizational environments where teams need reliability, maintenance, backup, access control, and predictable operations.

## Coming Soon

The first version of Ploinky Cloud is being prepared as a separately licensable offering for organizations interested in hosted Ploinky capabilities. Launch dates, commercial conditions, and pricing details will be announced when they are ready.

## Managed Capabilities

Ploinky Cloud will provide managed services around the core Ploinky platform.

| Managed capability | Role |
|---|---|
| Hosted agent environments | Provides ready-to-use Ploinky workspaces without local infrastructure setup. |
| Automatic scaling | Allocates compute resources according to workload and organizational needs. |
| Managed updates | Handles platform, infrastructure, and security updates. |
| Multi-tenant isolation | Separates organizations, users, workspaces, and agent environments. |
| Access control | Supports controlled access for users, teams, and organizational roles. |
| Monitoring dashboards | Provides observability for agent usage, runtime health, costs, errors, and activity. |
| Backup and disaster recovery | Protects workspace state and enables recovery after failures. |

## Licensing

Ploinky Cloud is not open source. It will be offered under a separate commercial license. Organizations interested in offering hosted Ploinky services to their own customers can explore licensing opportunities for providing Ploinky hosting.

Ploinky Cloud therefore has a dual role. It is a hosted product for organizations that want managed Ploinky workspaces, and it is a commercial licensing opportunity for partners that want to provide Ploinky hosting as a service.

## Early Access

Early access and licensing inquiries should be handled through direct contact with the Ploinky team. The initial cloud offering will focus on organizations that need hosted agent workspaces, managed operations, and commercial support.
