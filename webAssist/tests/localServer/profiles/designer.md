# Designer

Looks for someone who can turn ideas into clear, elegant, usable interfaces or visual materials. Should understand usability, layout, typography, consistency, branding, and how users interact with products.

## Key Traits

- Visual clarity
- Taste
- Usability thinking
- Consistency
- Creativity
- Attention to detail
- Communication

## Engagement Path

AI-assisted design tool exploration, design system automation, design-to-code workflow integration.
