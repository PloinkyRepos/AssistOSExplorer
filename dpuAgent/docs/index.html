Design Specifications

Confidential Data Boundary

Explorer needs a way to work with secrets, confidential files, comments, and access control without exposing protected values directly to the browser or scattering storage rules across multiple plugins.

Confidential Data Boundary

dpuAgent is that boundary. It mediates confidential workflows through an MCP contract that keeps metadata, ACL state, encrypted secret values, and protected content inside one runtime with identity-aware checks before materialization.

This keeps Explorer responsible for interaction flow, while the agent owns the secure storage semantics and permission enforcement.

How It Runs In Practice

Tool execution is routed through dpuAgent/tools/dpu_tool.sh and dispatched by dpu_tool.mjs. Explorer and other agents call the MCP surface for reads, writes, comment operations, and ACL mutations, while dpuAgent remains responsible for storage layout and access validation.

Validation rule: run npm test from dpuAgent/ for code changes, together with documentation updates.
