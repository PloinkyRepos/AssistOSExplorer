Explorer Help
A practical guide to your workspace
Your workspace

Find, understand, and work with your files

Explorer brings your files, documents, collaboration tools, and assistants into one place. Most actions follow the item you currently have selected.

Browse and open

Use the folder tree and file list to move through the workspace. Select a file to preview it, or open a folder to continue browsing.

Create and organize

Use the New menu and right-click menus to create, rename, copy, move, or delete files and folders. Available actions adapt to what you selected.

Preview and edit

Markdown, code, text, media, and structured documents open in the view that best suits them. Switch to editing when you need to make changes, then save your work.

Search and personalize

Use search to find content across the workspace. Open Settings to choose your theme, editor preferences, keyboard shortcuts, and the plugins you want to see.

Good to know: Explorer is the shared workspace surface. Features such as Git, Confidential, WebMeet, and Copilot are handled by separate agents and presented here when you need them.
Version control

Keep a clear history of your work

The Git button opens the workspace Git view. It shows repositories, changed files, branches, and the actions available for the current state.

  1. 1

    Set your identity

    Open Git settings and enter the name and email that should appear on your commits. These details identify your changes.

  2. 2

    Connect a remote account

    Choose GitHub sign-in for the guided flow, or use a personal access token for an HTTPS remote. Follow the on-screen confirmation before continuing.

  3. 3

    Start with a repository

    Create a repository on GitHub, clone one you can access, or enter a remote URL manually. You can also create a local repository from a folder's New menu.

  4. 4

    Review and share changes

    Select the files you want, write a meaningful commit message, and commit them. Pull before pushing when others may have updated the same repository.

Branches

Create or switch branches when you want to work separately from the main line of development.

Conflicts

If Git reports a conflict, review both versions carefully, keep the intended content, and complete the guided resolution before committing.

Behind the scenes: gitAgent manages repository operations and authentication while Explorer provides the interface.
Live collaboration

Meet and work together inside the workspace

WebMeet combines live audio and video with chat, shared workspace resources, and a collaborative blackboard.

Create or join a room

Open WebMeet to see available rooms. Create a room for a new session or join an existing one. A guest invitation lets someone enter only the room you shared.

Prepare your media

Choose your microphone and camera before joining. During the meeting you can mute, stop video, share your screen, and adjust participant audio.

Use chat and resources

Send messages to the room and attach relevant workspace resources when available. Guests can use room resources without browsing your workspace.

Work on the blackboard

Add notes, polls, lists, drawings, and supported documents to a shared canvas. Everyone in the room sees updates as collaboration progresses.

Privacy tip: Share only the screen, room link, and resources you intend participants to see. WebMeet and its live-media services run as separate agents from Explorer.
Protected information

Work with sensitive content deliberately

The Confidential area looks familiar, but its content is protected separately from ordinary workspace files and follows explicit access rules.

My Space

Your private confidential area. Create or upload sensitive material here when it is intended only for your account.

Shared

Items other people have shared with you appear here. What you can view, edit, or manage depends on the permission you received.

Secrets

Use this area for sensitive values such as access tokens. Secret values are treated differently from normal documents and should never be copied into ordinary files.

Permissions

Open an item's permissions before sharing it. Give only the access required, review who can use the item, and remove access when it is no longer needed.

Important: Moving through Confidential does not turn its items into normal files. dpuAgent protects the content and decides access according to the assigned roles.
AI assistance

Ask for help with the right workspace context

Copilot is most useful when you start from the file or folder related to your task and explain the outcome you want.

  1. 1

    Choose the context

    Right-click the relevant file or folder and choose Open Copilot here. The conversation starts with that workspace location in context.

  2. 2

    Describe the result

    State what you want to create, change, understand, or review. Mention important constraints and ask Copilot to clarify anything that would change the result.

  3. 3

    Follow progress

    Some coding or research requests continue as longer-running tasks. You can keep the conversation focused, review progress, and continue supported tasks with a new instruction.

  4. 4

    Review the outcome

    Read proposed changes and generated content before accepting or publishing them. You remain responsible for deciding what belongs in the workspace.

Skills

The Copilot section in Settings shows the skills discovered for the workspace. Skills give the assistant focused ways to handle particular tasks.

Specialized assistants

You can ask for coding, research, or other specialist help in natural language. Copilot selects an available specialist when the request needs one.

Behind the scenes: AchillesCLI manages Copilot conversations and coordinates separate specialist agents while Explorer supplies the selected workspace context.
Workspace administration

Manage access and available capabilities

Administration controls are shown only to authorized users. If you do not see one of these areas, your account does not currently have permission to use it.

Users and roles

In Settings → Administration, authorized users can add accounts, update names or passwords, assign roles, and remove accounts. A role determines which protected actions a user may perform.

Branding and audit

Administration also contains workspace login branding and audit settings. Use audit information to understand important activity without exposing confidential content.

Marketplace agents

Marketplace lists available agents. An admin can enable the capabilities the workspace needs and disable those that should not run.

Repository sources

The Repos area manages sources that provide agents, skills, or other workspace features. Install only repositories that your organization trusts.

Use care: Role changes, agent availability, and repository sources can affect everyone in the workspace. Confirm the intended scope before saving an administrative change.
