Version control

Keep a clear history of your work

The Git button opens the workspace Git view. It shows repositories, changed files, branches, and the actions available for the current state.

  1. 1

    Set your identity

    Open Git settings and enter the name and email that should appear on your commits. These details identify your changes.

  2. 2

    Connect a remote account

    Choose GitHub sign-in for the guided flow, or use a personal access token for an HTTPS remote. Follow the on-screen confirmation before continuing.

  3. 3

    Start with a repository

    Create a repository on GitHub, clone one you can access, or enter a remote URL manually. You can also create a local repository from a folder's New menu.

  4. 4

    Review and share changes

    Select the files you want, write a meaningful commit message, and commit them. Pull before pushing when others may have updated the same repository.

Branches

Create or switch branches when you want to work separately from the main line of development.

Conflicts

If Git reports a conflict, review both versions carefully, keep the intended content, and complete the guided resolution before committing.

Behind the scenes: gitAgent manages repository operations and authentication while Explorer provides the interface.
