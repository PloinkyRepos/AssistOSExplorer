OnlyOffice Runtime-v5 Documentation

The pinned OnlyOffice agent launches its mounted source entry point, then exposes an authenticated control service on private target 7000 and a narrowly public editor transport on private target 8080. Configuration verifies the exact canonical nginx file and relative alias before startup; after the pinned entrypoint materializes the alias, readiness requires distinct, byte-identical 105:107/0644 copies paired with the [::1]:8000 DocService listener. The wrapper also verifies callback storage, PostgreSQL, RabbitMQ/EPMD, and optional Redis with owner-aware listener checks. Explicit service targets never create physical-host publications.

Editor sessions resolve the current immutable topology generation. Each session has its own persisted, store-minted document key, and temporal body-bound JWTs protect editor configuration and callback/outbox traffic; the configurable lifetime is an exact positive integer capped at 300 seconds. A token from another session cannot authorize the opaque callback URL, even for the same document. The public proxy applies exact method, path, serialized-Origin, and WebSocket controls while stripping credentials, forwarding data, caller identity, and the private Ploinky Agent Assertion before reaching DocumentServer.

Durable v5 session state is an atomic, fsynced, guarded 0600 file under the persisted agent workdir and never contains delegation bearers. Missing or duplicate per-session document keys fail closed without a derivation fallback. DocumentServer Data and /var/lib/onlyoffice use explicit managed mounts; bundled PostgreSQL, RabbitMQ, and Redis data remain image-owned so rootless host ownership cannot block service startup. The browser gate prepares authenticated restart proof before creating a second edit, proves that edit absent from durable state, issues targeted restart without an intervening authentication request, and reopens the drain-persisted edit after replacement activation; invalid topology, signing, fetch, callback, persistence, listener ownership, or drain state fails closed.
