OnlyOffice Documentation

OnlyOfficeAgent is the Ploinky-managed decorator that fronts the workspace Document Server and owns Office session creation, signed editor config generation, loopback document/callback routes, the public editor proxy, and workspace-vs-DPU persistence routing. The agent declares its image (pinned via ${ONLYOFFICE_VERSION}), derived JWT secret, protected control route, public editor port, unpublished storage listener, readiness probe, and persistent storage in manifest.json.

Explorer remains the IDE shell and document picker. The DS specifications are the source of truth for runtime ownership, secret derivation, route separation, delegated DPU persistence, and Explorer integration.
