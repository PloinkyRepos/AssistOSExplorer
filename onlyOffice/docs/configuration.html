Documentation / Configuration

Configuration

The manifest defines the authenticated control target, public editor target, callback storage service, persistent service directories, generated secrets, and bounded session limits.

Targets And Persistent Services

The manifest declares target 7000 as authenticated control, target 8080 as public editor transport, and target 9100 as the internal callback storage service. It mounts only the agent-owned OnlyOffice log, data, and library directories at /var/log/onlyoffice, /var/www/onlyoffice/Data, and /var/lib/onlyoffice. PostgreSQL, RabbitMQ, and optional Redis remain image-owned internal support services and do not have separate persistent manifest volumes. The manifest also shares ONLYOFFICE_JWT_SECRET with the image's JWT_SECRET variable.

Service Controls

The manifest also controls callback input/output, drain timeout, and DocumentServer auto-assembly settings. The pinned image and startup hooks define the service ownership checks. Router targets remain internal container targets and do not declare separate physical-host publications.
