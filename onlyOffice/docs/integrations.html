Documentation / Integrations

Integrations

OnlyOffice coordinates Explorer, DocumentServer, DPU, and the Ploinky Router without transferring storage ownership or authenticated browser credentials to the public editor route.

Explorer And DocumentServer

Explorer opens Office documents through the authenticated control route and uses the returned session configuration to load the public editor transport. Browser Authorization headers, cookies, and unrelated credentials are not forwarded to DocumentServer.

Confidential Storage

For /Confidential paths, OnlyOffice uses the manifest-declared dpuConfidential delegation to call dpuAgent. The delegation is scoped to the declared Confidential tools and expires according to the Router grant. Ordinary workspace documents use the configured workspace storage path.

Ploinky Router

The control and editor routes are mediated by Ploinky. Browser URLs derive from the Router-authenticated forwarded origin, and direct local ports are not the browser contract.
