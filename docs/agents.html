Agents and Plugins

Explorer provides the shared workspace shell. The integrations below are declared by explorer/manifest.json or discovered from verified IDE-plugins manifests, while each owning agent keeps responsibility for its domain behavior and protected state.

Application Plugins

git

Git

Repository status, commits, branches, credentials, and Git menus.

 dpu-runtime-support

DPU

Confidential resources, permissions, secrets, research data, and jobs.

 soplang-builder

SOPLang

Structured document actions, variables, build, and execution workflows.

 tasks

Tasks

Backlog navigation, task creation, updates, and document task actions.

 webmeet

WebMeet

Meeting rooms, participants, media, Blackboard resources, and settings.

 workspace-monitor

Workspace Monitor

Administrator-only live metrics, history, thresholds, and log access.

Document and Supporting Agents

Multimedia

Document-level audio, image, video, preview, and FFmpeg integrations.

WebAssist

Workspace and guest-facing assistant chat integration.

WebMeet STT

Speech-to-text runtime used by supported WebMeet workflows.

WebMeet Scribe

Meeting Secretary transcription journal and notes reconciliation worker.

OnlyOffice

Office editor sessions, authenticated transport, callbacks, and persistence.

Explorer-Owned and External Entries

The help plugin is owned by Explorer and is covered by the runtime plugins guide. The manifest also enables Achilles CLI, WebTTY, LiveKit Server, Soul Gateway, and Umami as supporting dependencies. This checkout does not provide a local documentation entry page for those dependencies, so this index does not create unsupported links for them.
