Development Quick Reference

This page tracks practical setup and validation checks for the current Explorer implementation.

Bootstrapping

p-cli enable repo fileExplorer
p-cli enable agent fileExplorer/explorer global
export ASSISTOS_FS_ROOT=<workspace-root>
p-cli start explorer 8080

UI entrypoint: http://127.0.0.1:8080/explorer/index.html

Web Preview (HTML)

HTML preview uses repo-scoped file URLs. Example:

/.ploinky/repos/fileExplorer/docs/development.html?__previewReload=1

Required portability link (commit it):

explorer/.ploinky/repos/fileExplorer -> ../../..

Validation:

curl -I "http://127.0.0.1:8080/.ploinky/repos/fileExplorer/docs/development.html"
# expected: HTTP/1.1 200

WebSkel Refactor Notes

File Explorer UI is split into dedicated presenters/components:

  • file-exp: host/orchestrator
  • file-exp-entries: entries renderer and actions
  • file-exp-preview: preview presenter bridge
  • html-web-view: iframe presenter for HTML preview pane

Component registry source of truth: explorer/webskel.json

Useful Checks

# Unit tests
cd explorer
npm test

# Spot-check static docs path
curl -I "http://127.0.0.1:8080/.ploinky/repos/fileExplorer/docs/style.css"
