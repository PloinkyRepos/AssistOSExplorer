AchillesIDE

AchillesIDE provides an authenticated Ploinky workspace where Explorer combines filesystem navigation, previews, editing, and enabled agent workflows in one browser application. Explorer remains the shared shell; each domain agent remains responsible for its own protected operations.

How the workspace fits together

Core workspace capabilities

Files and folders

Create, rename, copy, cut, paste, upload, and delete supported workspace entries.

Find and replace

Find paths by name, search file content, select matches, and replace within a workspace scope.

Settings

Configure agents, plugins, shortcuts, editor auto-save, theme, avatars, and authorized administration surfaces.

Preview and editing

Open source files, Markdown, structured documents, media, and supported Office documents.
