multimedia Agent Overview

multimedia is primarily an IDE-plugin-focused agent for media attachments (audio, video, image, and generic files) in Explorer-style UI flows.

Compared to more orchestration-heavy agents (for example llmAssistant), this agent is centered on practical UI workflows: upload, metadata editing, preview, and video compilation actions.

Operational Role

The main surface is multimedia/IDE-plugins/, which publishes modal and embedded components for document, chapter, and paragraph contexts. In parallel, the agent includes the ffmpegImageToVideo skill for image-to-video generation with optional audio.

What the Agent Provides

  • plugins for uploading and managing audio/video/image attachments, including validation and metadata extraction;
  • video preview plugins (paragraph and document level) for fast output verification;
  • a document-level actions plugin for starting video compilation and downloading output;
  • an FFmpeg skill specialized for converting image batches to MP4.

Critical startup dependency: on agent startup, /code/scripts/install.sh is executed, and git plus ffmpeg are installed in the container to support video/audio/image attachment workflows.
